# Art. 4.

Le compte de gestion du receveur renseigne :

A. En recette :

- 1° L'excédant du compte précédent ;

- 2° Les reprises admises au même compte ;

- 3° Les recettes dont le comptable a été chargé d'opérer le recouvrement.

B. En dépense :

- 1° Le déficit éventuel du compte précédent ;

- 2° Les dépenses acquittées ;

- 3° Les reprises pour recouvrements restant à faire ;

- 4° Les sommes dont le comptable demande décharge comme irrécouvrables.
