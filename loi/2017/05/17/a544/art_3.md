# Art. 3. Intensité de l’aide

1) Lorsqu’une entreprise ou un organisme de recherche privé réalise un projet ou un programme de R&D s’identifiant à une activité de recherche fondamentale, de recherche industrielle ou de développement expérimental, les ministres ayant l’Économie et les Finances dans leurs attributions, désignés ci-après par " les ministres ", peuvent lui attribuer une aide dont l’intensité, calculée sur la base des coûts admissibles du projet ou programme, ne pourra pas dépasser les plafonds fixés ci-après:

- a) 100 pour cent pour les projets ou programmes de recherche fondamentale;

- b) 50 pour cent pour les projets ou programmes de recherche industrielle;

- c) 25 pour cent pour les projets ou programmes de développement expérimental.

(2) L’intensité de l’aide doit être arrêtée pour chaque bénéficiaire de l’aide, notamment dans le cas des projets ou programmes de collaboration.
