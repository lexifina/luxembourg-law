# Art. 17.

L’alinéa 4 de l’article 3 du Code de procédure pénale est modifié comme suit: Les juridictions de jugement, même lorsqu’elles constatent que le prévenu n’est pas pénalement responsable sur base des dispositions de l’article 71, alinéa premier du Code pénal, restent compétentes pour connaître de l’action civile dont elles avaient été préalablement et régulièrement saisies.
