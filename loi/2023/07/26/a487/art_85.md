# Art. 85.

Les employés communaux assumant les fonctions de directeur, de directeur adjoint ou de chargé de la direction, classés dans le groupe d’indemnité A1, bénéficient d’une majoration d’échelon pour fonctions dirigeantes. Pour ces agents, la valeur des différents échelons de leurs grades respectifs sont augmentés de 25 points indiciaires.

Toutefois, l’agent bénéficiaire d’une majoration d’échelon pour fonctions dirigeantes ne peut pas bénéficier d’une majoration d’échelon pour responsabilités particulières.
