# Art. 3.

L’article L. 211-3 du même code est modifié comme suit :

- 1° Aux points 1) à 26), la parenthèse fermante après les numéros est remplacée par le symbole ° ;

- 2° Le point 19° est modifié comme suit :

  - a) Les mots d’une chose ou à l’égard de celui qui effectue sur elle des travaux, sont supprimés ;

  - b) Le mot neuves entre les mots pièces et fournis est remplacé par le mot nouvelles.
