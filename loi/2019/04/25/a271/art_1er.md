# Art. 1er.

Le Code du travail est modifié comme suit :

- 1° L’article L. 232-2 prend la teneur suivante :

- Art. L. 232-2.

- Sont jours fériés légaux :

  - 1° le Nouvel An ;

  - 2° le lundi de Pâques ;

  - 3° le 1er mai ;

  - 4° la Journée de l’Europe ;

  - 5° l’Ascension ;

  - 6° le lundi de Pentecôte ;

  - 7° le jour de la célébration publique de l’anniversaire du Grand-Duc qui est fixé au 23 juin ;

  - 8° l’Assomption ;

  - 9° la Toussaint ;

  - 10° le premier et le deuxième jour de Noël.

- 2° L’article L. 233-4, alinéa 1er, prend la teneur suivante :

- La durée du congé est d’au moins vingt-six jours ouvrables par année, indépendamment de l’âge du salarié.
