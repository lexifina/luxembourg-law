# Art. 2.

À l’article 28-1, alinéa 1er, de la loi modifiée du 16 avril 1979 fixant le statut général des fonctionnaires de l’État, le point 1° prend la teneur suivante :

1° les jours fériés légaux suivants :

- a) le Nouvel An ;

- b) le lundi de Pâques ;

- c) le 1er mai ;

- d) la Journée de l’Europe ;

- e) l’Ascension ;

- f) le lundi de Pentecôte ;

- g) le jour de la célébration publique de l’anniversaire du Grand-Duc qui est fixé au 23 juin ;

- h) l’Assomption ;

- i) la Toussaint ;

- j) le premier et le deuxième jour de Noël ;
