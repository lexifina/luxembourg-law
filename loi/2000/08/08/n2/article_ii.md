# Article II.

L’article 3 du code d’instruction criminelle est complété par deux alinéas nouveaux de la teneur suivante:

Les juridictions de jugement, nonobstant l’acquittement intervenu sur base des dispositions de l’article 71, alinéa premier du code pénal, restent compétentes pour connaître de l’action civile dont elles avaient été préalablement et régulièrement saisies.

Si les juridictions d’instruction ordonnent un non-lieu sur base des dispositions de l’article 71, alinéa premier du code pénal, l’action civile est intentée ou poursuivie devant la juridiction civile.
