# Art. 1er.

L'article 1033 du code de procédure civile est complété par la disposition suivante: Les jours fériés sont comptés dans les délais. Toutefois, lorsque le dernier jour prévu pour faire un acte de procédure est un dimanche ou un autre jour férié légal, le délai est prorogé jusqu'au prochain jour ouvrable. Pour l'application de la présente disposition, le samedi est assimilé à un jour férié légal.
