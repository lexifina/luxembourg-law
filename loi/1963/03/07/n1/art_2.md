# Art. 2.

L'art. 298 du code civil est abrogé et remplacé par les dispositions suivantes: Art. 298. Dans le cas de divorce admis en justice pour cause d'adultère sur la base des articles 229 et 230 du code civil, l'époux coupable ne pourra se marier avec son complice qu'après le décès du conjoint offensé.
